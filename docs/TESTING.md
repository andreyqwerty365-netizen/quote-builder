# Проверки

## Автоматические тесты

Нужен Node.js 24+. Из корня проекта:

```sh
npm test
```

Текущий набор: **26 тестов** в четырёх файлах. Команда явно выбирает `tests/*.test.js`; временные файлы и копии релиза в проверку не попадают.

| Область | Покрытие |
| --- | --- |
| Деньги | Точка/запятая, целые копейки, скидки 0/100%, половина копейки вверх, бесплатная позиция, безопасный предел и переполнение |
| Ввод | Пустые/ошибочные реквизиты, целое количество от 1, цена от 0, существующая дата |
| Черновик | Все поля и промежуточные значения, сохранение/очистка, повреждённое и недоступное хранилище |
| Защита примера | Пример не заменяет введённые реквизиты, цену 0, изменённые количество/скидку или незавершённый ввод |
| Документ | Полная и частичная модель, отсутствие выдуманных сумм и мутаций черновика |
| HTTP | Публичные ресурсы, CSP, HEAD, запрет записи и доступа к внутренним файлам |

GitHub Actions настроен на Node.js 24, Ubuntu и Windows. Никакие пакеты не устанавливаются: workflow выполняет `npm test`. Конфигурация проверена локально; реальный прогон Actions возможен после размещения репозитория на GitHub.

## Браузерная приёмка

Выполнена в Edge 155 / Chromium на Windows, включая touch-эмуляцию.

- Демо: 90 000 ₽ до скидки, 9 000 ₽ скидка, 81 000 ₽ итог. Форма и документ совпадают.
- Добавление 3 × 10,05 ₽ даёт 81 027,13 ₽; удаление возвращает исходную сумму и удобный фокус.
- Проверены ошибочные цены/количества, скидка 101%, переполнение и переход к ошибочному полю при печати.
- Перезагрузка восстанавливает черновик, включая незавершённую цену. Отмена очистки и Escape сохраняют данные; подтверждение нового документа удаляет сохранение.
- Пример исчезает после ввода данных; даже программный вызов скрытого обработчика не перезаписывает документ.
- HTML в комментарии показывается текстом. Ошибка localStorage видна, редактор продолжает работать.
- Tab/Enter, skip-link, стрелки и Home/End для вкладок проверены. Ошибка печати из мобильного документа возвращает к форме.
- Оба режима проверены на 320, 360, 390, 600, 768, 1000, 1001, 1024, 1280 и 1440 px. Непредусмотренная горизонтальная прокрутка не обнаружена.
- После перехода на относительные URL отдельно проверена загрузка ресурсов при размещении статики в подпапке через браузерную route-фикстуру.

## Печать

Один DOM используется для экранного документа и печати. Проверены вызов обработчика печати, `beforeprint` и print-media; кнопки и редактор в печать не попадают.

Демосмета проверена на одном листе A4. Тестовое предложение с длинным названием, 50 позициями и большим комментарием заняло пять страниц A4. Текст PDF проверен на наличие всех 50 позиций, итога 4 500 ₽ и конца комментария. Все пять страниц отрендерены и просмотрены; заголовок таблицы повторяется, строки не разрываются. Редактирование после печати и последующее восстановление также проверены.

В репозитории сохранены снимки [одного A4](screenshots/print-a4.png), [первой](screenshots/print-multipage-first.png) и [последней](screenshots/print-multipage-last.png) страниц длинного предложения. Временные PDF, браузерные профили и полные журналы в публикацию не включаются.

## Границы проверки

Не проверялись реальные iOS/Android-устройства, Firefox/Safari, screen reader, физический принтер и ручное сохранение через системный диалог PDF. Браузерная печать проверялась через print-media и сгенерированный Chromium PDF. Проверки не заменяют тестирование этих сред.
